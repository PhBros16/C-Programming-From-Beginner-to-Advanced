Solução de Problemas e Pensamento Computacional

Antes de escrever uma linha de código, você precisa pensar como computador. Isso se chama pensamento computacional.

🔍

Quebrar problema grande em partes menores e gerenciáveis.

Abstração

📋
Algoritmo
Sequência finita e ordenada de passos para resolver um problema.

Pseudocódigo — Média de 3 notas

PSEUDOCÓDIGO
INÍCIO
  LEIA nota1, nota2, nota3
  media ← (nota1 + nota2 + nota3) / 3
  SE media >= 5 ENTÃO
    ESCREVA "Aprovado"
  SENÃO
    ESCREVA "Reprovado"
  FIM-SE
FIM

Fluxograma

FLUXOGRAMA
       [INÍCIO]
           │
   [Leia n1, n2, n3]
           │
   [media = (n1+n2+n3)/3]
           │
     ◇ media >= 5? ◇
      ↙ SIM    NÃO ↘
  [Aprovado]  [Reprovado]
      │             │
      └──────┬───────┘
           [FIM]

// 04 — operadores e tabela verdade disciplina

  
Operadores e Tabela Verdade

  
Operadores aritméticos

  
C

  
int a = 10, b = 3;
a + b  // 13   a - b  // 7
a * b  // 30   a / b  // 3  (divisão INTEIRA!)
a % b  // 1   (módulo = resto)
(float)a / b  // 3.33 (cast força divisão real)
a++;  a--;    // incremento / decremento
a += 5;       // a = a + 5

  
Operadores relacionais

  
C

  
a == b  // igual? (ATENÇÃO: == não é =)
a != b  // diferente?
a > b   // maior?   a < b  // menor?
a >= b  // maior ou igual?

  
Operadores lógicos

  
C

  
a > 0 && b > 0   // E lógico (AND): ambos verdadeiros
a > 0 || b > 0   // OU lógico (OR): pelo menos um
!(a == b)        // NÃO lógico (NOT): inverte

Estruturas de Repetição

  
C

  
// FOR — quando sabe quantas iterações
for (int i = 0; i < 5; i++) { printf("%d ", i); }

// WHILE — enquanto condição verdadeira
int n = 1;
while (n <= 10) { printf("%d ", n); n++; }

// DO-WHILE — executa pelo menos uma vez
do { scanf("%d", &n); } while (n <= 0);

break;    // para o loop imediatamente
continue; // pula para próxima iteração

// 13 — ponteiros ⭐ além da disciplina

  
Ponteiros

  
Ponteiros armazenam endereços de memória. O conceito mais poderoso do C.

  
C

  
int  x = 42;
int *p = &x;    // p aponta para x
printf("%d\n", x);   // 42
printf("%d\n", *p);  // 42 (derreferência)
*p = 100;
printf("%d\n", x);   // 100! (modificou x via ponteiro)

  
⚠️ Sempre inicialize! Use int *p = NULL; quando não tiver endereço ainda.
